# buildit-admissions

BuildIt AI 입시상담 공식자료 및 데이터베이스 프로젝트

## 프로젝트 목적

BuildIt AI 입시상담 Agent가 사용하는 공식 입시자료(대학 입시요강, 교육청 자료, 입시 일정 등)와
검증된 데이터베이스를 구축·관리하는 공개 저장소입니다.

수집된 자료는 BuildIt 본부에서 운영하는 입시상담 Agent의 답변 근거로 사용됩니다.
모든 자료는 공식 기관 발표 원문을 기준으로 하며, 출처와 적용 학년도를 명시합니다.

## 개발 담당

- 입시 DB 개발 및 자료 수집: **Qoder**
- 저장소 생성 및 접근 권한 관리: Muse

## 보안 주의사항

공개 저장소이므로 다음 정보가 포함되지 않도록 주의합니다.

- API 키, 비밀번호, 토큰 등 인증정보
- 개인정보 (이름, 전화번호, 이메일 등)
- 운영 DB 접속 정보
- 내부 시스템 구조 문서

## 디렉토리 구조 (예정)

```
buildit-admissions/
├── README.md
├── data/               # 검증된 입시자료 (출처·적용학년도 명시)
├── scripts/            # 수집·검증 스크립트
└── docs/               # 데이터 스키마 및 운영 문서
```
