# 2027 모집요강 판 대조 — adiga.kr 게시본 vs 입학처 게시본

작성 2026-11-05. 스크립트: `scripts/check_adiga_editions.py` · 결과: `data/validation/adiga_edition_check_2027.json` · 테스트: `tests/test_check_adiga_editions.py`

**데이터는 바꾸지 않았다.** 운영 DB·시드 변경 없음.

## 왜 했나
2027 전형·학과 인원·일정 데이터(`data/parsed/univ_sample`)는 각 대학이 대입정보포털(adiga.kr)에 올린 모집요강 파일로 만들었다(2026-11-02, 전국 187개교). 원문 링크를 입학처 주소로 바꾸려 했으나 다음 이유로 링크만 바꾸지 않았다.
- adiga 파일의 sha256이 기록돼 있지 않고(358건 중 9건만 md5), adiga는 robots가 막아 다시 받을 수 없다 → 입학처 파일과 같은 파일인지 증명할 수 없다.
- 판이 다른 것이 보였다(아래 '쪽 번호' 참고). 데이터의 근거 쪽(evidence_pages)은 adiga판 쪽 번호라, 링크만 바꾸면 쪽 번호가 다른 파일을 가리키게 된다.

대신 **값이 입학처판에도 그대로인지**를 확인했다.

## 범위
수능최저·정시 계산식 작업에서 입학처 게시본을 이미 받아 둔 23개교 37개 문서(adiga 기준).
- 글자 비교 34건, 쪽 이미지 직접 확인 2건(경기대 수시·용인대 수시 — 입학처판에 글자 층 없음)
- 제외 2건: 동덕여대 수시(입학처판이 HWP '배포용 문서' — 보호를 풀어 읽지 않음), 한국체육대 정시 재외국민 요강(다른 문서)

대학: 아주대, 추계예대, 동덕여대, 동국대, 이화여대, 홍익대, 한양대(ERICA), 서울한영대, 강서대, 한국체육대, 건국대, 광운대, 경기대, 감리교신학대, 세종대, 서경대, 숭실대, 성신여대, 차의과학대, 화성의과학대, 한경국립대, 서울시립대, 용인대

비교한 항목: 전형명, 전형 모집인원, 학과명, 학과별 전형 인원, 일정(날짜·시각).
비교하지 않은 항목: 지원자격·전형방법 문장, 수능최저 문장. (수능최저 판정 규칙은 처음부터 입학처판으로 따로 만들었다 — `docs/SUSI_MINIMUM_2027.md`)

## 결과 — 값 차이 0건
| 항목 | 확인한 값 | 입학처판과 다름 |
|---|---|---|
| 전형 모집인원 | 327 | 0 |
| 학과별 전형 인원 | 3,191 | 0 |
| 일정(날짜·시각) | 761 | 0 |
| 학과명 | 1,177 | 0 |
| 전형명 | 363 | 0 (표기 차이 4건, 아래) |

쪽 이미지 확인(경기대·용인대): 경기대 전형 14개 모집인원(전형요약 10쪽)과 일정 12건(17쪽), 용인대 전형 8개 합계(1~2쪽 합계 행)와 일정 12건(4쪽) 모두 일치.

자동 비교에서 '후보'로 나왔다가 쪽을 보고 일치로 판정한 것
- 전형 합계 중 원문에 합계가 따로 없는 것: 학과별 인원의 합과 같음(서경대·성신여대·서울시립대·동국대 등). 학과별 인원은 모두 확인됨.
- 군별로 나눈 인원: 이화여대 정시 농어촌 가11+나99+다7 = 원문 117.
- 인문·자연으로 나뉜 학과: 동국대 정시 컴퓨터·AI학부 80 = 원문 인문 7 + 자연 73.
- 표 글자 순서가 섞인 쪽: 서경대 정시 연기 10·피아노 8(쪽 이미지로 확인).
- 전형명 표기 차이: 동국대 정시 '기초생활수급자및차상위계층전형' ↔ 원문 '기초생활수급자및차상위계층(가군 / 나군 / 다군)'(41쪽) 3건, 건국대 정시 우리 이름에 군 안내를 덧붙인 '수능-특성화고교졸업자(…)' ↔ 원문 '수능(특성화고교졸업자)' 1건.

## 판 차이 (값은 같고 파일은 다름)
- 쪽 번호가 다르다: 동국대 정시 학과 인원표 adiga판 9쪽 → 입학처판 30쪽, 아주대 수시 adiga판 82쪽 / 입학처판 111쪽, 경기대·용인대는 입학처판이 디자인판(글자 층 없음)이고 adiga판은 글자 층이 있었다.
- 변경 공고(2026-10-14)
  - 동덕여대 정시: 화장품학전공 특성화고교 특별전형 '동일계열 기준학과' 목록 추가. 우리 데이터에 없는 항목이라 영향 없음.
  - 한국체육대 정시('가'군): 경기지도학과 선발방법에서 "각 종목별 수시 및 정시모집 선발인원의 합은 최대 3명" 문장 삭제(14·26쪽). 우리 전형방법 문장에는 이 문장이 없다 — 변경 후 내용과 같다.

## 남은 것
- adiga 링크는 그대로 둔다(대학이 직접 올린 공식 파일의 게시 위치, `docs/SOURCE_REGISTRY.md`상 링크·메타 보관 허용). 근거 쪽 번호는 adiga판 기준이다.
- 이번에 보지 않은 adiga 문서 321건(입학처판을 아직 받지 않은 대학). 같은 방식으로 보려면 대학별 입학처 게시본을 IpsiFetcher로 받아야 한다.
- 동덕여대 수시는 입학처판이 배포용 HWP라 비교하지 못했다.
