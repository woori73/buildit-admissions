# 2028학년도 대입 개편 — 상담 근거 시드

작성: 2026-11-13 · 상담 학년도 2028 (2029·2030학년도 질문도 서버가 같은 제도인 2028 자료로 찾는다)

## 요약

- **목적:** 입시상담 AI가 2028학년도부터 바뀌는 입시(내신 5등급제·통합형 수능·고교학점제)를 공식 발표 기준으로 답하게 한다. 아직 수집하지 않은 대학별 자료는 '수집 중'으로 안내한다.
- **적재본:** `data/seed/reform_2028/ipsi_seed_reform_2028.json`
  - 공식 제도 항목 `official_knowledge` 7건과 해석 항목 `youtube_knowledge` 7건이 들어 있다.
  - 만드는 법: `python3 scripts/build_reform_2028_seed.py`
- **서버:** feel2real-buildit PR(feat/admissions-2028-reform)이 `official_knowledge` 적재와 승격을 지원한다. 이 PR이 배포되기 전에 적재하면 `official_knowledge`는 무시된다.
- **적재 순서:** load/seed → activate-all(2028) → knowledge/reindex `{mode:"ALL"}`(임베딩 서버를 쓸 때)
