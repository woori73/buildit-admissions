## 원문 출처 원칙
- 각 대학 입학처가 게시한 2027 정시 모집요강 파일만 썼다. 대학어디가(adiga.kr)는 현재 robots가 수집 도구를 막아 쓰지 않았다.
- 모든 요청은 `IpsiFetcher`(robots 확인)를 거쳤다. 파일 주소는 입학처 페이지에 완성된 형태로 적힌 것만 썼다.
- 수능 점수만 계산한다. 학생부·실기·면접·학교폭력 감점은 넣지 않았다.
- 전국 최고 표준점수(`*_STD_MAX`)와 대학 변환표준점수(`*_CONV`)는 2027 수능 성적 통지(2026-12-11) 뒤 정해진다. 그 전에는 계산식만 있고 실제 점수는 낼 수 없다.

## 수집 과정에서 판단이 들어간 것 (사람 확인용)
- 광운대: 원문 파일이 입학처 페이지에 적힌 링크지만 도메인은 `iphak.jcoresystem.kr`(외부 호스팅)
- 한양대: 파일 주소가 href가 아니라 버튼 `onclick="window.open('/file/pdfDown.do?...')"`에 완성된 형태로 적혀 있음(계산식은 0개)
- 고려대·강서대: 페이지의 PDF 뷰어 iframe에 적힌 완성 주소로 받음
- 총신대: 첫 화면의 외부 스크립트 파일에 적힌 이동 주소를 따라감(결국 링크 없음으로 중단)
- 성공회대·추계예대: meta refresh / `location.replace` 이동 주소를 따라감
- 삼육대·한국성서대: 차단 사유 확인을 위해 robots.txt를 한 번 직접 조회(같은 User-Agent)
- 감리교신학대: 방화벽 차단 안내가 EUC-KR로 와서 수집 도구가 차단을 감지하지 못했음 → 수집 도구를 고침(`ipsi_fetch._decoded_text`, 테스트 추가). 고치기 전 첫 화면 한 건을 받았지만 수치는 쓰지 않음
- 광운대 원문 예시는 "가산점 미포함" 값이라, 대조 때 한국사 1등급 가산(+10)을 더한 값과 맞춤
- 등급표로 더하는 한국사 가산점이 있는 대학은 만점 입력 결과에 그 가산이 포함됨(형식 문서에 명시)
