## 3. 지원자격·특징 [T0/T2]
- 지역균형 = **학교장추천(고교별 2명)**, 동일 고교 졸업자 기준 등(p14). [T0]
- [T2 해석] 일반전형은 수능최저가 없어 **학생부종합 서류·면접 실력이 절대적**; 반대로 지원 자격 문턱은 넓음. 수능 최저를 피하려는 최상위 서류형 학생에게 유리, 수능 반영 없는 대신 면접·구술 대비 부담 큼.
