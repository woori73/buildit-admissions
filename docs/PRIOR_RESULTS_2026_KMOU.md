## 판단이 들어간 처리 (상세는 수집본 notes·`verification.name_mapping`)

- **이름 맞추기**
  - 같은 전형·모집단위를 파일마다 다르게 적었다. 예: '교과성적우수자'·'교과성적우수자전형'·'교과성적\n우수자전형', 성적 표는 '항해전공'만.
  - 같은 모집의 '지원 현황' 표 이름으로 맞췄다. 같은 단위가 상담 근거에서 여러 개로 갈라지지 않게 하려는 것이다.
  - 지원현황 표에 없는 이름 2개(정시 충원 표 '해양공간건축학부'·'전파융합공학전공')는 원문 그대로 두었다.
- **모집단위 이름 표기**
  - 학부·전공 칸은 ' / '로 이었다.
  - 원문이 남/여 값을 따로 적은 곳은 ' / 남'·' / 여'를 붙였다.
- **단과대학 단위 병합 칸**
  - 수시 특수교육대상자의 모집인원과 충원순위가 단과대학 단위 병합 칸으로 적혀 있다.
  - `통합모집(해양과학기술융합대학)`·`통합모집(해양인문사회과학대학)` 행으로 담았다(원문 표기 아님).
- **예비후보순위**
  - 충원 인원이 아니라서 지표 행(OTHER)으로 담았다.
  - 정시 표의 '남 8' 같은 값은 성별을 모집단위에 붙이고 숫자를 값으로 썼다. 원문 문자열은 `raw_value_text`에 둔다.
- **미공개 값**
  - 원문 주석: 등록인원 1명은 성적 미공개, 2명은 표준편차 미공개.
  - 빈 칸은 행으로 만들지 않았다.
